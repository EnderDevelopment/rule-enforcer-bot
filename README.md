# Rule Enforcer Bot

A Discord bot to enforce server rules with ease

## Features

- Ban users with a simple command
- Provide a reason for the ban

## Requirements

- Python 3.8 or higher
- discord.py
- dotenv
- python-dotenv

## Installation

1. Clone the repository
2. Install the required packages: `pip install -r requirements.txt`
3. Create a `.env` file based on `.env.example` and add your Discord bot token

## Usage

1. Invite the bot to your server
2. Use the `/ban` command to ban a user who violates the rules

## Configuration

- `DISCORD_TOKEN`: Your Discord bot token
